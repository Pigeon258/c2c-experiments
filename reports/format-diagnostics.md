# 输出格式与重复生成

对 P1 的同一批输出重新计分，模型和生成结果固定。正式报告保留原规则，下面仅比较改变答案提取方式后的结果。

| 方向 | GSM8K 严格 → 宽松数值 | HumanEval 原样 → 格式修整 |
|---|---:|---:|
| M1 | 355 → 483 / 1,319 | 71 → 71 / 164 |
| M2 | 923 → 951 / 1,319 | 96 → 96 / 164 |
| M3 | 99 → 474 / 1,319 | 42 → 45 / 164 |

数学重评识别最后明确给出的数值，包括标签空白、自然语言和等价数值写法。未作答、只列出多个数字或只有推导中的中间值，均不能据此补分。M3 有 984 题缺少规定的 `####` 标记，严格成绩对输出格式尤其敏感。

HotpotQA 对严格判错的回答分层抽样。每方向在「候选答案命中」和「未命中」两层各抽 20 题，共 120 题。保留严格正确项，并按层大小加权；将待定项分别判错或判对，所得内容正确率估计为 M1 50.4%–53.2%、M2 70.6%–74.7%、M3 40.4%–43.4%。这是抽样判定范围，不是全量重评或置信区间。

代码题尝试从既有回答中取出可运行补全，修整包装、重复函数等形式，再执行原题测试。任一修整版本通过即记为恢复。三方向共额外通过 3 题，均属于 M3。[逐题结果与实例](humaneval.md)
